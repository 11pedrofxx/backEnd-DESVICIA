# DESVICIA — Backend

Plataforma de apoio à superação de vícios e à construção de hábitos saudáveis.

## Sobre o projeto

O **DESVICIA** é um projeto de TCC desenvolvido como requisito para a conclusão do **Curso Técnico em Informática do Instituto Social Nossa Senhora de Fátima**.

A plataforma busca auxiliar pessoas no processo de superação de vícios por meio do acompanhamento diário, desenvolvimento de hábitos saudáveis e uma rede social focada em apoio.

Este repositório contém o backend da aplicação, responsável pelo gerenciamento dos dados, autenticação dos usuários e comunicação com o frontend.

## Tecnologias utilizadas

- Node.js
- Express
- MySQL
- JavaScript
- JWT
- bcrypt
- Google OAuth

## Funcionalidades

- Cadastro, login e recuperação de senha.
- Autenticação e proteção de rotas.
- Gerenciamento de vícios e hábitos.
- Check-ins diários e acompanhamento de progresso.
- Registro de gatilhos e estratégias.
- Contatos de emergência.
- Conquistas e comunidade com postagens, curtidas e comentários.
- Painel administrativo.

## Estrutura do projeto

O backend utiliza uma arquitetura organizada em camadas:

- **Controller:** recebe e responde às requisições.
- **Service:** contém as regras de negócio.
- **Repository:** realiza a comunicação com o banco de dados.

## Integração

O backend funciona integrado a um frontend separado, responsável pela interface da plataforma.

## Objetivo acadêmico

Projeto desenvolvido para fins acadêmicos, Trabalho de Conclusão de Curso (TCC) do Curso Técnico em Informática do Instituto Social Nossa Senhora de Fátima.
